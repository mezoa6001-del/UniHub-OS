# Core Values

Version 1.0

---

# Why Values Matter

Technology changes.

Markets change.

Products evolve.

Our values do not.

These principles guide every decision made inside UniHub.

---

# 1. Students First

Students are the reason UniHub exists.

Every feature, every lesson, every update should improve the learning experience.

When making decisions, always ask:

"Will this help students learn better?"

If the answer is no, we don't build it.

---

# 2. Medical Accuracy

Trust is everything.

Educational content must be:

- Evidence-based
- Reviewed
- Updated regularly
- Transparent about references

We never sacrifice accuracy for speed.

---

# 3. Simplicity

Medical education is already difficult.

The platform shouldn't be.

We remove unnecessary complexity.

Simple products create better learning.

---

# 4. Continuous Improvement

Nothing is ever finished.

Every course,
every question,
every feature,
and every workflow
can become better.

We improve every day.

---

# 5. Ownership

Every team member owns their work.

Problems are solved.

Mistakes are admitted.

Solutions are shared.

Success belongs to the team.

---

# 6. Innovation with Purpose

We don't add AI because it's popular.

We use technology only when it genuinely improves learning.

Innovation must always solve a real problem.

---

# 7. Build for Scale

Every decision should support future growth.

Write documentation.

Design reusable systems.

Think long-term.

Avoid shortcuts that create technical debt.

---

# 8. Data-Informed Decisions

We respect data.

We measure:

- Learning outcomes
- Student engagement
- Completion rates
- Satisfaction

But numbers never replace common sense.

---

# 9. Respect

Respect students.

Respect instructors.

Respect teammates.

Respect feedback.

Respect time.

Professionalism comes before everything else.

---

# 10. Never Stop Learning

We expect our students to learn every day.

We expect the same from ourselves.

Curiosity is part of our culture.

---

# Decision Framework

Before implementing any feature, ask:

✓ Does it improve learning?

✓ Is it medically accurate?

✓ Is it simple?

✓ Can it scale?

✓ Would we be proud to ship it?

If any answer is "No", rethink the solution.

---

# Our Promise

We are not building the biggest medical platform.

We are building the platform that students trust the most.

Trust is earned one lesson, one question, and one decision at a time.
