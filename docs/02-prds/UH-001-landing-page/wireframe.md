# UH-001 — Landing Page Wireframe

Version: 1.0

Status: Draft

---

# Goal

The landing page should clearly explain UniHub, build trust, and guide visitors to create an account or explore courses.

The design should be simple, modern, and optimized for conversion.

# Design Goals

The first screen should answer three questions within five seconds:

1. What is UniHub?

2. Why should I trust it?

3. What should I do next?
