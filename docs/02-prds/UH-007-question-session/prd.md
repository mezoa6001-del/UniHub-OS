# Executive Summary

The Question Session enables students to answer questions in an exam-like environment and receive instant feedback after submission.

---

# Business Goals

- Increase daily practice.
- Improve student performance.
- Track learning progress.

---

# User Stories

As a student,

I want to solve questions one by one,

so that I can test my understanding.

---

As a student,

I want to review my mistakes,

so that I can improve.

---

# Functional Requirements

The system shall allow students to:

- Start a session.
- Navigate between questions.
- Select answers.
- Submit the session.
- Review answers.
- View score and statistics.

---

# Business Rules

Questions cannot be modified after submission.

Each question has one correct answer.

The session result is stored automatically.

---

# Success Metrics

- Session Completion Rate
- Average Score
- Questions Solved per Student

---

# Acceptance Criteria

- Session starts correctly.
- Answers are saved.
- Score is calculated correctly.
- Results are displayed immediately.

---

# Out of Scope

- AI-generated explanations
- Leaderboards
- Competitive mode
