# UH-008 — Subscription

| Field | Value |
|-------|-------|
| Feature ID | UH-008 |
| Version | 1.0.0 |
| Status | Approved |
| Priority | P1 |

---

# Executive Summary

The Subscription module allows students to purchase access to UniHub plans and determines which educational content they can access.

---

# Business Goals

- Generate recurring revenue.
- Manage student access.
- Support future pricing plans.

---

# User Stories

As a student,

I want to subscribe to a plan,

so that I can access premium courses.

---

As a student,

I want to know when my subscription expires,

so that I can renew it.

---

# Functional Requirements

- View available plans.
- Purchase a subscription.
- View active subscription.
- View expiry date.
- Renew subscription.

---

# Business Rules

Only active subscriptions unlock premium content.

Expired subscriptions lose premium access immediately.

---

# Acceptance Criteria

- Plans displayed correctly.
- Subscription activates after successful payment.
- Expiry calculated correctly.

---

# Out of Scope

- Coupons
- Family Plans
- Gift Subscriptions
