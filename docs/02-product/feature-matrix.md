# Release Philosophy

## MVP (v1.0)

Deliver a complete learning platform.

Students should be able to study from start to finish without needing another platform.

---

## Version 1.1

Improve usability.

Reduce friction.

Increase student satisfaction.

---

## Version 1.2

Increase engagement.

Help students stay organized.

Encourage daily study habits.

---

## Version 2.0

Introduce Artificial Intelligence.

AI should make studying easier without changing the core learning experience.

---

## Version 3.0

Transform UniHub from a learning platform into an intelligent medical education ecosystem.

---

# Rule

A feature is added only if it solves a real problem for students.

Features are not built because competitors have them.

They are built because students need them.
