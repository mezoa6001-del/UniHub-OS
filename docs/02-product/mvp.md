# Minimum Viable Product (MVP)

Version 1.0

---

# Purpose

The MVP defines the smallest version of UniHub that delivers real value to medical students.

The objective is simple:

Launch fast.
Learn from users.
Improve continuously.

---

# MVP Goal

A medical student should be able to:

- Create an account.
- Subscribe to a course.
- Watch lessons.
- Solve questions.
- Track progress.

Nothing more is required for Version 1.0.

---

# MVP Principles

Every feature must satisfy at least one of these conditions:

- Improves learning.
- Solves a real student problem.
- Generates revenue.
- Reduces support workload.

If not, it is postponed.

# Success Criteria

The MVP is successful when:

- Students can complete an entire course.
- Students solve questions regularly.
- Payments work reliably.
- Instructors can publish courses independently.
- Admins can manage the platform without developer intervention.
