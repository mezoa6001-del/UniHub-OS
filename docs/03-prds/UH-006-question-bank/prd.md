# Executive Summary

The Question Bank allows students to browse and launch question sessions organized by course, chapter, and topic.

It serves as the entry point for assessment and exam preparation.

---

# Business Goals

- Increase daily engagement.
- Improve exam performance.
- Increase question-solving activity.

---

# User Stories

As a student,

I want to browse questions by chapter,

so that I can practice specific topics.

---

As a student,

I want to know how many questions are available,

so that I can plan my study session.

---

# Functional Requirements

The page shall display:

- Courses
- Chapters
- Question Count
- Difficulty Level
- Estimated Time
- Previous Performance (if available)

Students can start a new question session.

---

# Business Rules

Only enrolled students can access premium question banks.

Question counts update automatically.

Hidden question banks are not displayed.

---

# Success Metrics

- Sessions Started
- Questions Solved
- Daily Practice Rate

---

# Acceptance Criteria

- Question banks load successfully.
- Students can browse by chapter.
- Session launch works correctly.

---

# Out of Scope

- Question Solving
- Results
- Review Answers
