# UH-011 — Admin Dashboard

| Field | Value |
|-------|-------|
| Feature ID | UH-011 |
| Version | 1.0.0 |
| Status | Approved |
| Priority | P1 |

---

# Executive Summary

The Admin Dashboard enables platform administrators to manage all operational aspects of UniHub through a centralized interface.

---

# Functional Requirements

The dashboard shall provide:

- User Management
- Instructor Management
- Course Management
- Subscription Management
- Payment Monitoring
- Reports
- System Settings
- Audit Logs

---

# Business Rules

Only administrators can access this dashboard.

Every administrative action must be logged.

---

# Acceptance Criteria

- Admin authentication required.
- CRUD operations available.
- Audit logs generated.
